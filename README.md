# Productivity Telegram Bot

Бот для ежедневной продуктивности: утренний вопрос, напоминание в середине дня, вечерний чекин.

## Функции
- Утренний вопрос: «Какое одно дело сделает твой день успешным?»
- Напоминание в середине дня о записанной задаче
- Вечерний чекин: выполнил ли задачу?
- Подсчёт серии выполненных дней (streak)
- Двуязычный интерфейс: русский и английский

## Установка и запуск

### 1. Получи токен бота
Напиши @BotFather в Telegram → /newbot → скопируй токен.

### 2. Установи зависимости
```bash
pip install -r requirements.txt
```

### 3. Запусти локально (для тестирования)
```bash
TOKEN=твой_токен_здесь python main.py
```

### 4. Деплой на Railway
1. Залей папку на GitHub
2. Зайди на railway.app → New Project → Deploy from GitHub
3. Добавь переменную окружения: TOKEN = твой_токен
4. Готово — бот работает 24/7

## Структура файлов
```
├── main.py          # Точка входа, сборка бота
├── handlers.py      # Логика диалогов с пользователем
├── scheduler.py     # Расписание утро/день/вечер
├── db.py            # База данных (SQLite)
├── texts.py         # Все тексты на RU и EN
├── requirements.txt # Зависимости
├── Procfile         # Инструкция для Railway
└── .gitignore       # Защита токена
```
